## How Alpha Anywhere Sits

Alpha Anywhere does not replace the database you already administer. It sits beside that engine as a named UX builder for Alpha Anywhere web apps on business data you own.

If two people share a PC, each keeps an Alpha Anywhere project desk of their own. Extra screens wait for their own title instead of crowding the live builder.

A first visit should be one short UX, then the same Alpha Anywhere business data the next day. That is enough to see if the layout holds on a project you administer.

## After a Week

A week in Alpha Anywhere is not more live components. It is the same UX builder, a shorter project list, and a note that still makes sense on Monday. If every screen is pinned, nothing stands out.

Take finished components off the live set so the next visit starts on the Alpha Anywhere web apps that are still open.

Other programs stay where they are. Alpha Anywhere only keeps the path back: project name, UX builder, business data, handoff.
Leave Alpha Anywhere with a quieter project desk than the one you opened.

Alpha Anywhere is easier to trust when the project desk stays smaller than the script folder it came from. Name the web app, keep the UX builder on data you administer, finish one visible component, and write what changed.
